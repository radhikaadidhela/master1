# Radhika Salesforce Workspace for VS Code + Codex

Open this folder as the workspace root in VS Code. Codex should read `AGENTS.md` first, then the relevant files under `context/` and `interview-prep/`.

This bundle consolidates the Salesforce knowledge currently available from the project context, uploaded resumes, prior Agent 360/Data 360 notes, and recent interview feedback. It intentionally excludes highly sensitive identity documents (EAD, driver's license) and raw interview audio because those are not needed for coding/interview context and should not be copied into a development workspace.

## Contents
- `AGENTS.md` — persistent Codex instructions and accuracy rules.
- `context/` — Salesforce profile, Apex/architecture/integrations, LWC, Agentforce/Data 360, cloud/product topics, DevOps/security/performance.
- `interview-prep/` — recent interviewer feedback and answer bank.
- `resume/` — current Salesforce resume variants available in this project.
- `reference/` — preserved detailed prior Data 360/Agent 360 source notes.
- `job-search/` — job targeting preferences.
- `code-examples/` — place future Apex/LWC/SFDX examples here.

## Important
This is a consolidated working knowledge base, not a verbatim export of every historical ChatGPT conversation. Some older chat turns are represented through the available project context/summary rather than raw transcripts. Keep future Salesforce notes/files in this workspace so Codex can use them consistently.
